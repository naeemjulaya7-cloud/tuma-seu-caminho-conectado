# TUMA: Seu Caminho Conectado

Crie uma landing page e interface de produto moderna, elegante, credível e visualmente marcante para uma Progressive Web App chamada TUMA.

A TUMA é uma plataforma de entregas por proximidade em que o cliente escolhe um ponto de recolha e um ponto de entrega, publica o pedido, recebe candidaturas de vários entregadores próximos e escolhe quem realizará a entrega. Os entregadores podem deslocar-se a pé, de chapa/transporte público, bicicleta, mota ou carro.

Quero que o design pareça um produto real, maduro e cuidadosamente desenhado por uma equipa de UX/UI experiente.

A interface deve chamar atenção, transmitir segurança e confiança, mas NÃO deve parecer um template genérico, um dashboard SaaS ou algo claramente gerado por inteligência artificial.

DIREÇÃO VISUAL

Criar uma estética:

- moderna

- urbana

- elegante

- humana

- premium

- clean

- intuitiva

- mobile-first

- com personalidade própria

Quero evitar:

- excesso de gradientes

- excesso de glassmorphism

- blur exagerado

- cards todos iguais

- arredondamento excessivo

- ícones decorativos demais

- ilustrações genéricas

- aparência de startup SaaS genérica

- visual muito futurista

- composição excessivamente simétrica

- excesso de elementos apenas para preencher espaço

A interface deve parecer natural, refinada e funcional.

IDENTIDADE VISUAL

Usar uma paleta com:

Laranja principal:

#FF5A1F

Laranja escuro:

#D9470D

Azul petróleo / teal:

#0F5C5E ou tom semelhante

Carvão escuro:

#191919

Off-white:

#FAF8F4

Branco:

#FFFFFF

Cinza claro:

#EEEAE5

Cinza médio:

#76716D

Verde para sucesso/verificação:

#2E7D5B

O laranja deve ser a principal cor de acção e identidade, mas não deve dominar toda a página.

O teal deve trazer equilíbrio, confiança e profundidade visual.

A maior parte da interface deve usar off-white, branco e carvão.

TIPOGRAFIA

Usar uma tipografia moderna e muito legível, como:

- Manrope

ou

- Inter

Títulos com peso forte e bastante personalidade.

Texto de apoio mais discreto.

Evitar títulos gigantes em todas as páginas.

A tipografia deve fazer parte da identidade do produto.

LOGOTIPO

Criar um logo simples para TUMA.

Preferir:

- logotipo tipográfico

- pequeno símbolo abstracto associado a trajecto, movimento ou ligação entre dois pontos

Evitar:

- caixa genérica

- mota genérica

- carrinha

- pin de localização cliché

HERO SECTION

A hero deve ser a secção mais marcante da página.

Quero uma composição desktop em duas zonas:

LADO ESQUERDO:

- pequeno badge: “Disponível em Moçambique”

- headline forte

- subtítulo curto

- botão principal “Solicitar entrega”

- botão secundário “Ser entregador”

Headline sugerida:

“Envie qualquer coisa,

de um ponto para outro,

com pessoas verificadas.”

Pode melhorar a frase, mas deve manter um tom simples, humano e memorável.

Abaixo dos CTAs, mostrar discretamente:

- Identidade verificada

- Entregadores próximos

- Confirmação segura

LADO DIREITO:

Criar um mockup muito elegante da própria aplicação mostrando:

- mapa

- área seleccionada

- ponto de recolha

- destino

- lista de entregadores próximos

- fotografia

- nome

- rating

- distância

- meio de transporte

- botão “Escolher”

O mockup deve parecer uma interface real e não uma ilustração conceptual.

IMAGEM DA HERO

Usar uma imagem fotográfica real e autêntica como elemento visual importante da hero section.

A imagem deve mostrar:

- ambiente urbano

- cidade africana/lusófona

- ruas, edifícios ou rooftops

- sensação de movimento e proximidade

- luz natural

- aparência real

Evitar:

- stock genérico

- ilustração artificial

- render 3D

- imagem com aparência de IA

A imagem pode ocupar parte do fundo ou aparecer integrada atrás do mockup do produto.

Usar overlay subtil para preservar contraste e legibilidade.

HEADER

Criar navbar elegante com:

- logo TUMA

- Início

- Como funciona

- Ser entregador

- Entrar

- Criar conta

O header pode ter cantos suaves e fundo claro, mas deve parecer refinado e discreto.

COMO FUNCIONA

Criar uma secção com 4 passos:

1. Escolha no mapa

Defina o ponto de recolha e destino.

2. Receba candidatos

Entregadores próximos podem candidatar-se.

3. Escolha com segurança

Compare distância, transporte, avaliação e verificação.

4. Confirme a entrega

Use códigos de confirmação na recolha e destino.

Os blocos não devem parecer quatro cards genéricos exactamente iguais.

Criar uma composição mais editorial e dinâmica.

SEGURANÇA

Criar uma secção forte que transmita confiança.

Destacar:

- BI verificado

- selfie de verificação

- telefone verificado

- histórico de entregas

- código de recolha

- código de entrega

- possibilidade de reportar incidentes

Usar elementos visuais simples, sofisticados e claros.

TIPOS DE ENTREGADORES

Mostrar que qualquer pessoa verificada pode fazer entregas usando:

- a pé

- chapa/transporte público

- bicicleta

- mota

- carro

Não usar emojis.

Usar ícones vectoriais consistentes.

4. Escolher destino

5. Detalhes da encomenda

6. Resumo do pedido

10. Entregador seleccionado

11. Entrega em andamento

12. Confirmar recolha

13. Confirmar entrega

14. Histórico

15. Avaliação

16. Reportar problema

FLUXO DO ENTREGADOR

Criar telas para:

1. Onboarding

2. Verificação de telefone

3. Verificação de BI

4. Selfie

5. Estado da verificação

6. Dashboard

7. Disponível / indisponível

8. Pedidos próximos

9. Detalhes do pedido

10. Candidatar-se

11. Candidatura enviada

12. Entrega activa

13. Confirmar recolha

14. Confirmar entrega

15. Histórico

UX/UI

Priorizar:

- excelente hierarquia visual

- bom uso de whitespace

- navegação simples

- componentes consistentes

- microinterações subtis

- feedback de loading, erro, sucesso e offline

- mapa bem integrado

- layouts mobile muito bem resolvidos

- desktop pensado separadamente, não apenas uma versão mobile ampliada

LINGUAGEM VISUAL DE ROTA

Criar uma assinatura visual consistente baseada em:

ponto de recolha

linha/trajecto

ponto de destino

Exemplo conceptual:

●──────●

Usar esta linguagem em:

- cards de pedidos

- histórico

- detalhe de entrega

- mapas

- estados da entrega

COPY

Usar linguagem simples, humana e directa.

Evitar frases genéricas como:

“Revolutionizing logistics”

“Transforming delivery”

Preferir frases como:

“Envie algo de um ponto para outro.”

“Escolha quem leva a sua encomenda.”

“Pessoas verificadas, perto de si.”

“A pé, de chapa, bicicleta, mota ou carro.”

RESULTADO ESPERADO

Quero uma interface:

- muito bonita

- moderna

- elegante

- natural

- memorável

- credível

- localmente relevante

- com qualidade internacional

O resultado deve parecer um produto real pronto para ser usado por pessoas em Moçambique.

A interface deve chamar atenção pela composição, tipografia, fotografia, identidade e clareza — não por efeitos artificiais.

A regra principal é:

“menos efeitos, mais design.”

Não criar uma interface que pareça feita por IA.
